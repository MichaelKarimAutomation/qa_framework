QA Framework - Docker Installation Guide

Step 1: Prerequisites

  • Docker Desktop must be installed and running. See Windows Installation Guide for instructions.
  • Clone the qa_framework repository to your machine via GitHub Desktop.

Step 2: Environment Variables

  • In the project root, create a .env file using .env.example as a reference.
  • Fill in all values.

Step 3: Build the Docker Image

  • Open a terminal in the project root and run: 
    docker build -t qa-framework .

Step 4: Run the Tests

  • Run: 
    make docker-run
  • All tests should pass.
