qa-framework documentation
==========================

``pom/``, ``utils/``, ``data/``, and ``tests/`` is documented directly from
each module's docstrings — keep the docstrings up to date and these pages
will follow.

To rebuild::

   make docs

The rendered site lands in ``docs/_build/html/`` (open ``index.html``).
