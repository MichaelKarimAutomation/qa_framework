Makefile

Auto-generated reference for the project Makefile. Run any target with make <target>.

make help

List all available commands

python scripts/help.py

make report

Serve Allure test report in browser

allure serve reports/allure-results

make clean

Delete generated reports

python scripts/delete_reports.py

make docs

Generate HTML API documentation under docs/_build/html

python scripts/generate_docs.py

make test

Run full test suite after deleting reports folder

python scripts/delete_reports.py & pytest tests/ -v

make smoke

Run smoke-tagged tests only

pytest tests/ -v -m smoke

make regression

Run regression-tagged tests only

pytest tests/ -v -m regression

make parallel

Run full test suite in parallel

pytest tests/ -v -n auto

make lint

Check code style with ruff

ruff check .

make format

Auto-format code with ruff

ruff format .

make docker-build

Build the Docker image

docker build -t qa-framework .

make docker-run

Run the Docker container with .env vars

docker run --rm --env-file .env qa-framework
